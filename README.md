> A decentralized, immutable land registry system built on the Ethereum blockchain. Register, trade, and transfer land titles with cryptographic security and full transparency.

## ✨ Features

### 🏠 Core Functionality
- **Land Registration** - Register new land parcels with unique parcel IDs
- **Property Marketplace** - List and buy land titles with ETH
- **Ownership Transfer** - Securely transfer property ownership
- **Transaction History** - Complete audit trail of all transfers
- **Role-Based Access** - Registrar role for official land verification

### 🎨 User Interface
- **Cyberpunk Aesthetic** - Premium dark theme with neon accents
- **Glass Morphism** - Modern frosted glass card design
- **Real-time Dashboard** - Live statistics and metrics
- **Search & Filter** - Advanced marketplace filtering
- **Responsive Design** - Works on all devices

### 🔒 Security Features
- **Immutable Records** - Blockchain-backed ownership proof
- **OpenZeppelin Standards** - Industry-standard security
- **MetaMask Integration** - Secure wallet connection
- **Duplicate Prevention** - Unique parcel ID verification
